# registro-assenze.

Quest'app è prettamente destinata agli alunni dell'istituto Rizza-Insolera A.S. 2026/27, ma il codice è pubblico qualora qualcuno volesse intraprendere un progetto simile, è un app per tracciare le assenze scolastiche: segna assenze, entrate/uscite posticipate, ritardi e assemblee. Calcola automaticamente le ore accumulate e ti dice quante ne restano prima del limite.
